# 🚀 Quick Start & Usage Guide for Jafurah Simulator

This guide assists reservoir engineers and data scientists in executing the `jafurah_simulator.py` engine on local machines.

## 1. Prerequisites & Environment Setup
Ensure you have **Python 3.8 or higher** installed. Clone this repository and navigate to the directory:

```bash
git clone https://github.com
cd jafurah-unconventional-frac-protocol
```

## 2. Install Required Dependencies
Install the necessary mathematical libraries using pip:

```bash
pip install -r requirements.txt
```

## 3. Running the Simulator
To execute the baseline verification and run the AI optimization modules, run the script from your terminal:

```bash
python jafurah_simulator.py
```

## 4. Expected Console Output Dashboard
Upon successful execution, the terminal will print the intellectual property verification header for **Eng. Awsan Sultan** and display three distinct reporting matrices:
1. **Volumetrics Matrix:** Displays total stages, low-sulfate water barrels, and local silica proppant tonnage.
2. **Geomechanical Risk Assessment:** Analyzes inter-well space parameters to evaluate Frac Hit risks.
3. **AI Automated Actions:** Demonstrates real-time screen-out predictive actions, automated rig path optimizations, and NLP text mining from historical fields.
